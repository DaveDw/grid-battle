# Brief: events between battles

Right now each sector is three battles in a row, and the only choice between fights is picking 1 of 2 cards. Propose **10 short events** that can appear on the sector map between battles. Think of the event rooms in Slay the Spire or FTL.

## What an event can touch (only these, so it can be built)
- **Squad HP:** it carries between battles within a sector. Fallen units return at 25%. Clearing a sector heals the squad.
- **The deck:** cap 12; the leader card can't be removed. An event can add a card (from any faction, see `roster.md`), remove one, upgrade one by lowering its cost, or duplicate one.
- **The next battle:** e.g. the enemy starts with less HP; you start with more energy; a sector modifier from `roster.md`'s list; the enemy deck gets an extra card.
- **The run:** skip a battle, or take a harder one for a better card choice (pick 1 of 3 instead of 1 of 2).

## For each event write
1. Title and a 2-3 sentence scene, set in this game's world:
   - Terran Partition Authority, Ascendancy League, Manyworlds Resistance and the Long Tomorrow at war over planets;
   - the leaders' commands as their mottos ("Hold the Line", "Take the Ground"...).
2. **2-3 choices**, each with an exact outcome and numbers.
3. At least one choice with a real cost or risk. No free lunches: a good event is a hard choice.
4. Which faction, if any, it's tied to. Some events could react to the player's own faction.

Keep the text short: it's read on one screen. Use the proposal header from `kb/README.md`.
